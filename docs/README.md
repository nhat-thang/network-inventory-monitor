# Tài liệu kiến trúc

Đặt tài liệu kiến trúc (`.docx`/`.pdf`, khoảng 20 trang) vào thư mục này. Tài liệu gồm 9 chương theo mục 6.2 của đề:

1. Giới thiệu
2. Cơ sở lý thuyết
3. Kiến trúc tổng thể
4. Thiết kế hướng đối tượng
5. Thiết kế chi tiết
6. Môi trường triển khai
7. Kết quả thực nghiệm
8. Đánh giá và hướng phát triển
9. Tài liệu tham khảo và phụ lục

Ảnh sơ đồ (kiến trúc, class diagram, sequence diagram) lưu trong `docs/diagrams/`.
